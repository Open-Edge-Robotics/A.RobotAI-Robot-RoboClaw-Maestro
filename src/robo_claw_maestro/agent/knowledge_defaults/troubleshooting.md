# Troubleshooting

계획을 세우거나 실패 후 다시 계획할 때(replan) 참고하는 대응 규칙입니다.

## 실패 유형별 대응

| 실패 | 대응 |
| --- | --- |
| `BLOCKED` (경로 막힘) | 다른 경로나 다른 로봇으로 재배정하고, 같은 경로를 바로 다시 시도하지 않습니다. |
| `TIMEOUT` | Task를 더 작은 단위로 나누고 timeout을 늘리기보다 범위를 줄입니다. |
| 배터리 부족 | 해당 로봇을 제외하고 남은 Task를 다른 로봇에 배정합니다. |
| 물체를 찾지 못함 | 탐색 구역을 넓히거나 다른 로봇의 관찰 Task를 추가합니다. |
| 같은 실패 2회 반복 | 더 시도하지 않고 summary에 사람 확인 필요라고 적습니다. |
